# LeadFlow Kenya - One-Page Quick Reference

**🎯 Mission:** Build a WhatsApp lead manager for Kenyan real estate agents and reach KES 100K MRR in 3 months.

---

## 📊 THE NUMBERS

**Market:**
- 12,000 agents in Kenya using WhatsApp
- 5,000 viable customers (handle 30+ leads/month)
- 1K-10K monthly searches for real estate keywords

**Pricing:**
- Starter: KES 2,000/month
- Professional: KES 4,500/month  
- Agency: KES 12,000/month

**Economics:**
- CAC: KES 4,000-6,000
- LTV: KES 36,000
- LTV:CAC: 9:1
- Gross Margin: 88.5%
- Breakeven: 36 customers

**Revenue Path:**
- Month 1: 5 customers = KES 10K MRR
- Month 3: 50 customers = KES 100K MRR (profitable)
- Month 6: 200 customers = KES 400K MRR (KES 224K profit/month)

## 🎓 TECH STACK

**Frontend:** Next.js 14 + Tailwind CSS  
**Backend:** Next.js API routes  
**Database:** Supabase (PostgreSQL)  
**Auth:** Supabase Auth  
**WhatsApp:** Baileys (open source)  
**Payments:** M-Pesa Daraja API  
**Hosting:** Vercel + Railway  

**Why:** Fast to build, scales well, Kenya-friendly, free tier covers first 50 customers.
